# 部署方法说明（最终版）

> 这份是**唯一**需要照着做的部署文档，取代 `部署方案.md` 与 `部署-简洁版.md`。
> 目标：把 `网页` 目录跑成一个能用 HTTPS 打开的服务。
> 只有一条铁律：**反向代理必须关闭响应缓冲**，否则答题页面不会实时刷新。

---

## 0. 前置条件

| 项 | 要求 |
|---|---|
| Node.js | ≥ 18，推荐 22 或 24 LTS（`node -v` 确认） |
| 目录 | 全英文路径，如 `C:\vocab-battle\web`（避开空格，命令行不用反复加引号） |
| 端口 | 网关 `3000`（只给本机反代用）；游戏服务器 `18848`（**只允许本机**） |
| 域名/证书 | 已有（这套东西不含证书配置） |
| 防火墙 | 入站只放行 `80` / `443`。**不要**放行 3000 / 18848 |

服务器上最终长这样：

```
C:\vocab-battle\
├─ web\                ← 整个 网页 目录的内容
│  ├─ gateway\         Node 网关
│  ├─ public\          前端（唯一需要改的界面层）
│  ├─ bin\
│  │  └─ vocab_battle.exe    C++ 游戏服务器
│  ├─ data\            词库 words.csv + 成绩 csv（自动生成）
│  └─ package.json
└─ logs\
```

`tests\`、`design\`、`.backup-*` 可以不传（不影响运行）。

## 1. 先手动跑通，再接反代

```powershell
cd C:\vocab-battle\web
node gateway\server.js
```

看到两行才算成功：

```
服务器进程已启动（端口 18848）
网关已启动：http://127.0.0.1:3000（服务器端口 18848）
```

另开一个窗口验证：

```powershell
curl http://127.0.0.1:3000/api/health
# 期望：{"ok":true,"room":"running","phase":"lobby","sessions":0}
```

浏览器打开 `http://127.0.0.1:3000/?mock=1`，能进大厅就说明前端没问题（mock 模式不依赖服务器）。
再打开 `http://127.0.0.1:3000/`，能进大厅说明 C++ 服务器也通了。

> 先手动跑的作用：把「程序本身有问题」和「反代配置有问题」分开，排错时不用猜。
> 确认没问题后 `Ctrl+C` 停掉。

## 2. 反向代理：加一段配置

页面靠 **SSE 长连接**接收对局状态，所以这两行不能省：
`proxy_buffering off`（nginx）/ `flush_interval -1`（Caddy）。

**nginx**（宝塔：网站 → 设置 → 配置文件，粘在 `server{}` 里）：

```nginx
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_buffering off;          # 关键：SSE 必须立即推送
    proxy_read_timeout 3600s;     # 长连接，别让 60s 默认值断开
    client_max_body_size 16k;     # 接口都是小 JSON
}
```

**Caddy**：一条域名指令就够（把 `va.example.com` 换成你自己的域名）。

```caddy
va.example.com {
    reverse_proxy 127.0.0.1:3000 {
        flush_interval -1
    }
}
```

反代一缓冲的表现是：**大厅里别人加入了但我不刷新**、**点了提交没反应，过一会儿一起跳出来**。

## 3. 让它后台常驻

**最简：任务计划程序**（图形界面，不装别的东西）

- 触发器：计算机启动时
- 操作：`C:\Program Files\nodejs\node.exe`，参数 `gateway\server.js`，起始于 `C:\vocab-battle\web`
- 勾「不管用户是否登录都要运行」「使用最高权限运行」，并设置「任务失败时每 1 分钟重试」

**更稳：NSSM**（能一起结束 C++ 子进程，推荐长期用）

```powershell
cd C:\vocab-battle
.\nssm.exe install VocabBattle "C:\Program Files\nodejs\node.exe" "gateway\server.js"
.\nssm.exe set VocabBattle AppDirectory "C:\vocab-battle\web"
.\nssm.exe set VocabBattle AppStdout "C:\vocab-battle\logs\gateway.log"
.\nssm.exe set VocabBattle AppStderr "C:\vocab-battle\logs\gateway.log"
.\nssm.exe set VocabBattle Start SERVICE_AUTO_START
.\nssm.exe start VocabBattle
```

安装时在 Shutdown 页勾上 **Kill process tree**，否则停服务后 `vocab_battle.exe` 会残留占端口。

## 4. 上线前 6 条验证

1. `netstat -ano | findstr 18848` → 只出现 `127.0.0.1:18848`（不该是 `0.0.0.0`）。
2. 从另一台电脑 `Test-NetConnection 服务器IP -Port 18848` → 应为 **False**（外网连不进游戏端口）。
3. 防火墙入站只有 80/443。
4. 浏览器打开 `https://你的域名` → 证书正常、看到加入页、Console **无报错**。
5. 手机 + 电脑各进一个：加入 → 大厅 → 开始 → 答题（**重点看是否实时刷新**）→ 结果 → 终局。
6. 答题中刷新页面，应回到当前这道题；公屏发一条消息，两端都能看到。

## 5. 更新版本（以后每次改完就这 4 步）

```powershell
# 1. 停（先停网关，再确认 exe 也退了——网关会在 exe 退出 1 秒后自动拉起它）
nssm stop VocabBattle
# 2. 确认干净
tasklist | findstr vocab_battle     # 不该有输出
# 3. 覆盖文件（见下表）
# 4. 起
nssm start VocabBattle
```

| 改了什么 | 要覆盖什么 |
|---|---|
| 只改界面（`public/`） | `web\public\` |
| 改了网关（`gateway/`） | `web\gateway\` |
| 改了 C++（`src/`） | `web\bin\vocab_battle.exe`（重新编译后） |
| 词库 | `web\data\words.csv`（**覆盖前先备份**，成绩 csv 不要动） |

> 2026-10-20 那轮同时改了 `bin/` 和 `gateway/` 和 `public/`，三样都要一起换，只换 public 会出现
> 「题型不一致」「抢答不判分」这类看起来像前端的现象。

## 6. 排错对照

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面能开，但别人加入我不刷新 / 提交后没反应 | 反代在缓冲 SSE | 加 `proxy_buffering off` 或 `flush_interval -1` |
| 打开就白屏 | 用 `file://` 双击打开了 | 必须走 `http://` |
| 502 Bad Gateway | 网关没起，或端口不是 3000 | `netstat` 看 3000 是否监听；看 `logs\gateway.log` |
| 加入时提示「服务器程序未找到」 | `bin\vocab_battle.exe` 不在 | 补上文件或改 `BIN` 环境变量 |
| 提示「房间正在重启」 | C++ 进程刚崩，网关正在自动拉起 | 等 1–2 秒重试；连续出现就看日志里的 `[服务器]` 行 |
| 重启后进不去对局 | 游戏端口被残留进程占住 | 结束 `vocab_battle.exe` 再启动服务 |
| 没有声音 | 页面加载后用户还没点过任何地方 | 先点一次「进入擂台」（浏览器自动播放策略） |
| 公屏发不出 | 答题进行中（有意限制） | 等本题结束；或看是不是 1.2 秒内连发 |

**看日志**：`logs\gateway.log` 里 `[服务器]` 开头的是 C++ 的输出，其余是网关自己的。

## 7. 安全要点（别省）

1. `TCP_HOST` 默认 `127.0.0.1`，**不要改成 `0.0.0.0`**。改了等于绕过网关把游戏端口暴露到公网（没有鉴权）。
2. 网关本身没有登录，任何拿到网址的人都能加入——**网址不要公开**。
3. 游戏数据全在内存，重启即清空（只有成绩写到 csv）。别把它当持久化服务用。
4. `/api/stats` 是公开的（战绩抽屉要用），里面只有昵称和分数，没有敏感信息。

## 8. 课前自测（同一 WiFi，不占用域名）

```powershell
set HOST=0.0.0.0
node gateway\server.js
```

学生用 `http://你的内网IP:3000` 访问。**仅限自己教室的局域网测试**，测完改回默认（只听本机）。
