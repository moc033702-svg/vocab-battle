## 0. 动手前必须知道的 8 条

1. **只改 `public/`**。不碰 `src/`、`gateway/`、`tests/`。
2. **不改任何已有类名 / ID / 属性名**（钩子清单见 `美化交接书.md` 第 5 节）。本方案只**新增**类名，见第 13 节。
3. **不删** `#app[data-same="1"] .screen { animation: none; }`。
4. **整屏重建规则**：每收到一份新视图，`#app` 里的 DOM 全部重建。所以：
   - 名单、排行、选项的**选中态、已提交态不要加 `@keyframes` 动画**（别人一提交就整屏重建，动画会重播，看起来像卡顿）。只用静态样式。
   - 想要「入场编排」，只能挂在 `#app[data-same="0"]` 下（这个值只在换屏/换轮的那一次渲染为 0，同屏刷新为 1，所以不会重播）。第 10 节有现成写法。
   - 不要给任何一行加 `infinite` 动画。
5. **所有文字继续走 `h()`**（textContent），不要出现 `innerHTML`、`insertAdjacentHTML`、`outerHTML`。图标也用 `h('svg')`/`h('path')` 生成（`dom.js` 已支持 `svg/path/circle/rect/g`，**不要改 `dom.js`**）。
6. CSS 分两种改法：
   - **A 类（原地修改）**：第 1 节的设计令牌、第 2.3 节的 hover 包裹、第 2.4 节的聚焦样式。
   - **B 类（追加）**：其余样式全部写进 `style.css` **文件末尾**新增的「第三轮润色」区块，用同等或更高的选择器覆盖旧规则。这样出错时整块删掉就能回滚。
7. 暗色变量在 `style.css` 里**出现两次**（`@media (prefers-color-scheme: dark)` 里一份、`:root[data-theme="dark"]` 一份），两份必须**一字不差地同步修改**。
8. 不用网络字体、不用 CDN、不加 npm 依赖、不加构建步骤。图标用内联 SVG，favicon 用 data URI。

### 2.4 键盘聚焦样式（A 类，原地）——修一个真问题

现在的 `:focus-visible` 里有 `border-radius: var(--radius-xs);`，**它会改写被聚焦元素自身的圆角**：用 Tab 键聚焦「开始比赛」「提交」这些胶囊按钮时，按钮会瞬间变成 6px 方角。改成：

```css
:focus-visible {
  outline: 2.5px solid var(--accent);
  outline-offset: 3px;
}
```

（删掉 `border-radius` 那一行即可。现代浏览器的 outline 会自动贴合元素圆角。）

### 14.1 终局并列名次（新增，`ui/screens.js` 的 `finalScreen()`）

名次规则用**竞赛排名**：同分同名次，下一个名次跳号（两人 6 分 → 第 1、第 1、第 3）。

**找到这段（现在 `pos` 同时身兼名次和槽位）：**

```js
  const podium = (pos) => ranking.find((r) => r.rank === pos);
  const order = [2, 1, 3].map((pos) => ({ pos, row: podium(pos) })).filter((x) => x.row);
```

**改成（槽位只管金银铜与高度，名次按分数重算）：**

```js
  // 并列名次：同分同名次，下一个跳号（1,1,3）
  const ranks = ranking.map((r, i) =>
    (i > 0 && ranking[i - 1].score === r.score) ? null : i + 1);
  for (let i = 1; i < ranks.length; i++) if (ranks[i] === null) ranks[i] = ranks[i - 1];

  // 槽位固定：2 = 左（银）、1 = 中（金）、3 = 右（铜）；i 是排序后的下标
  const order = [{ slot: 2, i: 1 }, { slot: 1, i: 0 }, { slot: 3, i: 2 }]
    .filter(({ i }) => ranking[i])
    .map(({ slot, i }) => ({ slot, i, row: ranking[i], rank: ranks[i] }));
```

**`pod()` 里把 `pos` 全部换成 `slot` / `rank`：**

```js
  const pod = ({ slot, i, row, rank }) => h('div', { class: `pod pod-${slot}${row.id === view.me.id ? ' is-me' : ''}` },
    i === 0 ? h('span', { class: 'crown', 'aria-hidden': 'true' }, icon('crown', 'icon-fill')) : null,
    avatar(row.name),
    h('span', { class: 'pod-name' }, row.name,
      i > 0 && rank === ranks[i - 1] ? h('span', { class: 'pod-tie' }, '并列') : null),
    h('span', { class: 'pod-score' }, `${row.score} 分`),
    h('div', { class: 'pod-block' }, h('span', null, String(rank))));
```

要点：
- 皇冠只给排序第一的人（`i === 0`），不给并列者，否则会出现两个皇冠；
- 名次数字用 `rank`（可能是 1、1、3），块的颜色与高度仍由 `slot` 决定；
- 并列的人名字后面加「并列」小标签，避免「站在第 2 级台子上却写着第 1 名」的困惑。

**表格与头部同步改：**

```js
  // 表格：ranking.map((r) => …) 改成 ranking.map((r, i) => …)，单元格 String(r.rank) → String(ranks[i])
  // 头部：不要再用 f.myRank（服务器给的是不并列的名次）
  const myIndex = ranking.findIndex((r) => r.id === view.me.id);
  const myRank = myIndex >= 0 ? ranks[myIndex] : f.myRank;
  // 然后把 `第 ${f.myRank} 名` 换成 `第 ${myRank} 名`
```

**新增类名（记得补进第 13 节的新增清单）：**

```css
.pod-tie {
  margin-left: 4px;
  font-size: 11px;
  font-weight: 700;
  padding: 1px 5px;
  border-radius: 999px;
  color: color-mix(in srgb, var(--gold-text) 88%, var(--text));
  background: var(--gold-soft);
  vertical-align: 1px;
}
```

**已知取舍**：`f.champion` 仍是服务器排序的第一人，并列时标题只写一个人（「擂台冠军：小明」，而小红也显示第 1 名）。
觉得别扭时只需判断 `ranks.filter((x) => x === 1).length > 1` 后把标题改成「并列冠军：…」，本轮不做。
