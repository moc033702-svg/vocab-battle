## 1. 顺手修掉的一个真 bug

轮次进度条原来是 `grid-template-columns: repeat(10, 1fr)`，写死 10 列。
选了 3 轮时，3 个段只占整行 30% 的宽度，右边空一大截；选 15 轮又会挤成一条。

改成按实际轮数均分：

```css
.round-bar { display: grid; grid-auto-flow: column; grid-auto-columns: 1fr; gap: 5px; }
```

## 3. 答对 / 答错的动画与音效

**音效**：`public/audio/correct.wav`（C5–E5–G5 上行三连音 + 一颗高音，0.57s）、
`public/audio/wrong.wav`（A3→F3 下行两音，带轻微下沉，0.48s）。单声道 44.1kHz，各约 40–50KB。
生成脚本在 `tools/gen-audio.py`（可选工具，不参与运行）。
**想换音色：直接覆盖这两个 wav，代码不用动；想调参数就改脚本重跑。**

播放逻辑在 `public/js/feedback.js`：

- 每轮同一个结论只播一次（整屏重绘不会重复播），离开结果屏后自动复位；
- 答对 → correct.wav；答错 / 超时 → wrong.wav；**被抢先不播**（那不是答错）；
- 加入房间时预加载，避免第一次播有延迟；
- 浏览器拦截自动播放时静默失败，不报错。

**动画**（`style.css` 里 `fx-*` 与 `is-anim` 部分）：

- 答对：卡片上浮回弹 + 图标弹性放大 + 绿色光环扩散 + 右上角「+N」上浮消散 + 全屏绿色柔光一闪；
- 答错：卡片左右抖动 6 次 + 图标「盖章」砸下 + 全屏红色柔光一闪；
- 系统开了「减少动态效果」时，沿用文件末尾的全局规则，动画会被压到 1ms（等于不播）。
